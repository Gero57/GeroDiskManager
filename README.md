# Gero Disk Manager

Native macOS catalog manager for external disks. The GitHub Actions workflow builds a ready-to-open Apple Silicon `.app` bundle and publishes it as a downloadable artifact.

## Build
Push to `main` or run **Build Gero Disk Manager** from Actions. Download the artifact named `Gero-Disk-Manager-macOS-arm64`.

The app catalogs file and folder names and paths; it does not modify source files on disks.


Build workflow is triggered on every push to the main branch.
